# Developer Portfolio

My personal software engineering portfolio, built to present my background, technical skills, and selected projects in a responsive, interactive format.

**Live site:** [joshuacherenfant.com](https://joshuacherenfant.com)

## Overview

The portfolio gives recruiters and engineering teams a focused view of my full-stack, backend, frontend, and Android development experience. It highlights the engineering work behind projects such as a cinema e-booking system, a roommate and apartment discovery application, and native Android applications.

## Features

- Responsive layouts designed for desktop, tablet, and mobile screens
- Reusable React components for project, skills, experience, and contact sections
- Interactive visual components and motion effects
- Project cards linking to source repositories and supporting details
- Contact form integration using EmailJS
- Custom domain deployment

## Technology stack

- **Framework:** Next.js with the App Router
- **Languages:** TypeScript, JavaScript
- **UI:** React, Tailwind CSS
- **Contact:** EmailJS
- **Tooling:** Git, GitHub, ESLint, npm
- **Deployment:** Cloudflare Workers

## Engineering focus

This project demonstrates component-based frontend architecture, responsive UI development, reusable design patterns, third-party service integration, and iterative refinement across multiple viewport sizes.

## Run locally

```bash
git clone https://github.com/JoshuaCS01/developer-portfolio.git
cd developer-portfolio
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

The contact form requires valid EmailJS configuration to send messages. The rest of the portfolio can be viewed locally without it.
